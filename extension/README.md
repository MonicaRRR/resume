# 浏览器一键填表（实验）

从本机「经历库」填写**当前活动标签页**上的在线简历表单。  
启发式匹配 + 本机已配置模型补洞；**缺项留空并提醒**；**绝不自动投递 / 选岗**。

## 前置条件

1. 本机后端已启动：`make dev`（API 在 `http://127.0.0.1:8000`）。
2. 经历库已保存姓名等字段（网页「个人经历库」）。
3. （可选）在「模型设置」配置好模型，未匹配字段才会走 Agent 补洞；否则仅规则填写。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge：`edge://extensions`）。
2. 开启「开发者模式」。
3. 「加载已解压的扩展程序」，选择本仓库的 `extension/` 目录。
4. 打开招聘网站的投递 / 简历编辑页，点击扩展图标 → **填写当前页**。

## 行为约定

| 规则 | 说明 |
|---|---|
| 目标页 | 仅当前活动标签页 |
| 数据源 | `GET/PUT` 经历库；不编造内容 |
| 缺字段 | 留空，并在弹窗列出提醒 |
| 禁止 | 不点击投递 / 提交 / 申请类按钮 |
| 策略 | 无站点专属选择器；通用 label/placeholder 启发式，再 Agent |

## 本机 API

- `POST /api/autofill/plan`：传入页面字段快照，返回 `actions` / `empty_reminders` / `warnings`
- 若已配置模型且未显式传 `provider`，会自动使用当前配置做 hybrid 补洞；失败则降级为纯规则并写入 `warnings`

## 合规提示

本扩展仅辅助填写表单，提交与投递须你本人确认。请遵守各招聘平台用户协议，勿用于未经授权的自动化批量投递。
